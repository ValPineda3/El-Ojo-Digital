# El-Ojo-Digital
Sistema Inteligente para la detección y clasificación de transacciones fraudolentas en compras en línea.

#   Descripción
El ojo digital es un proyecto orientado al desarrollo de un sistema inteligente capaz de analizar transacciones de compras en línea y clasificarlas de acuerdo con su nivel de riesgo de fraude.

El sistema utilizará técnicas de inteligencia artificial y análisis de datos para identificar patrones asociados con posibles operaciones fraudulentas y proporcionar información que apoye la detección temprana de transacciones sospechosas.

# Problema
Las compras en línea se han convertido en una actividad cotidiana, pero también presentan riesgos relacionados con transacciones fraudulentas. La identificación de operaciones sospechosas puede resultar complicada cuando existe una gran cantidad de transacciones que deben analizarse en poco tiempo.

Por ello, surge la necesidad de desarrollar una herramienta que permita analizar las características de una transacción y detectar patrones asociados con posibles comportamientos fraudulentos, proporcionando una clasificación del nivel de riesgo para apoyar la identificación temprana de operaciones sospechosas.

# Objetivo General
Desarrollar un sistema inteligente capaz de analizar transacciones de compras en línea y clasificarlas de acuerdo con su nivel de riesgo de fraude mediante el uso de técnicas de inteligencia artificial y análisis de datos.

# Objetivos Particulares
- Diseñar una base de datos que permita almacenar y organizar información relacionada con usuarios, transacciones y características relevantes para el análisis de fraude.
- Implementar un módulo de análisis que procese las características de las transacciones para identificar patrones asociados con posibles operaciones fraudulentas.
- Desarrollar un mecanismo de clasificación que determine el nivel de riesgo de una transacción en las categorías bajo, medio o alto.
- Desarrollar una interfaz que permita consultar las transacciones analizadas y visualizar su nivel de riesgo junto con los principales factores asociados al resultado.

# Alcance
El proyecto contempla el desarrollo de una plataforma web para el análisis de transacciones de compras en línea.

El sistema permitirá:
- Registrar y consultar información de las transacciones.
- Almacenar información relacionada con usuarios y compras.
- Analizar las características de las transacciones.
- Utilizar un modelo de inteligencia artificial para apoyar la detección de posibles fraudes.
- Clasificar las transacciones en niveles de riesgo bajo, medio o alto.
- Mostrar los principales factores asociados al resultado del análisis.
- Almacenar los resultados de los análisis.
- Consultar el historial de transacciones analizadas.

# MVP - Producto Mínimo Viable
El Producto Mínimo Viable de FraudGuard AI consiste en una plataforma web capaz de recibir los datos principales de una transacción de compra en línea, procesarlos mediante un modelo de inteligencia artificial y mostrar un nivel de riesgo de fraude clasificado como:
- Bajo
- Medio
- Alto

Como parte del resultado, el sistema mostrará los principales factores considerados durante el análisis y almacenará el resultado de la evaluación para su posterior consulta.

# Ejemplo de funcionamiento

Una transacción puede contener información como:
- Monto de la compra.
- Hora de la transacción.
- Ubicación.
- Dispositivo utilizado.
- Número de compras recientes.
- País habitual de compra.
El sistema analizará estas características y proporcionará una clasificación de riesgo.
